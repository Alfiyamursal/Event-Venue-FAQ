# Event-Venue-FAQ
The Event Venue Recommendation System is a web-based application developed using Python and Streamlit.
This system helps users find suitable venues for events such as weddings, corporate meetings, birthday parties, and college functions based on budget, capacity, and location.

The application also provides data visualization and intelligent insights to help users make better decisions.
# Objectives

To simplify the process of selecting an event venue

To filter venues based on budget and capacity

To analyze venue data efficiently

To provide AI-based insights for better decision making

To create an easy-to-use web interface

An intelligent web-based application that helps users find the best event venue based on budget, capacity, location, and event type.
Built using Python, Streamlit, and Data Analysis tools, this system simplifies venue selection through filtering and visualization.

🚀 Live Features

🔍 Filter venues by budget

👥 Filter venues by capacity

📍 Location-based search

📊 Data visualization with charts

🤖 AI-powered insights (optional – OpenAI API)

💻 Simple and interactive Streamlit UI
